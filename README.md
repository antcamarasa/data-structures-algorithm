# Data Structures & Algorithms, from scratch in Java
 
> I rebuild every data structure by hand, then put it to work on real problems.
 
Every piece of software rests on a handful of data structures. A database finds a row through a tree, a cache answers through a hash table, a map app computes a route through a graph, and your editor's undo button is a stack. Frameworks and languages change every few years; these foundations don't.
 
So I learn them from the inside instead of just calling them from a library. My conviction is simple: **solid foundations first, everything else builds on them.**
 
I started a year ago, and I try to do a little every day.
 
## How I work
 
Every topic goes through two steps:
 
| | Step | What I do |
|:-:|---|---|
| 🔨 | **Build** | I recode the structure or the algorithm in Java, from scratch, without `java.util` collections. Then I work out the complexity of each operation myself. |
| 🧩 | **Problem solving** | I use what I built on exercises, and I write down the key idea of each solution. |
 
One rule: **I build it before I use the `java.util` version.** Once I know what's inside, I'm allowed to use the library.
 
Each topic has its own page: my definition, what I built, the problems I solved, the pitfalls I hit.
